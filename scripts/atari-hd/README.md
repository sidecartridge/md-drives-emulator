# atari-hd has moved

The Atari ST hard-disk image builder previously here is now its own
repo: <https://github.com/sidecartridge/atari-hd>.

It's a stdlib-only Python image builder with both a TUI and a
scriptable CLI; the output is a raw `.img` compatible with the ACSI
emulation in this firmware. See that repo's README for the one-line
installer and usage.
